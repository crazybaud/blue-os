# Description

Press `Cmd+Shift+A` (macOS) or `Ctrl+Shift+A` (Windows): a single modal
creates the complete action — Id, slug, frontmatter, sections. Nobody types a
file name. The other shortcuts: Cmd+Shift+J Journal, Cmd+Shift+I Information,
Cmd+Shift+D Decision, Cmd+Shift+B normalize.
